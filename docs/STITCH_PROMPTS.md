## ITERATION NOTES

### Colors to verify in Stitch output:
- Background: must be T-01 #0A0A0A or T-02 #141414 — never navy, never ivory
- No hue present in the UI layer — flag any blue, coral, amber, or ivory tint
- Ruled lines and section numbers: Platinum Mist #C8C8C8 only
- Ghost buttons only — flag any filled, colored, or gradient button
- Tonal scale flows dark→light: verify headlines at Pure Aperture #FAFAFA on T-01/T-02 grounds

### Typography to verify:
- Headlines should read as Cardo (high-contrast Renaissance serif, editorial)
- Labels/nav should read as Garet (geometric sans, uppercase, tracked 0.10–0.20em)
- Body should read as Garet (regular weight, natural tracking)
- Flag any instance of Cormorant, Jost, or Inter

### Layout to verify:
- Void space: any screen should feel 40–50% empty — flag if too dense
- No rounded corners on primary containers
- No drop shadows on images (editorial flat)
- No box borders on form fields (bottom border only)
- No color CTAs — ghost button treatment everywhere
